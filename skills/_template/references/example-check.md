# 示例 reference 文件

## 这份文件是干什么的

`references/` 放**细节**：规则表、边界情况、领域知识、长流程。`SKILL.md` 只留入口、触发条件和硬规则。

这样做的原因是**渐进披露**：agent 只有在真正加载技能时才读 `SKILL.md`，只有真正需要细节时才去读 `references/`。把全部内容堆进 `SKILL.md` 会让每次加载都变贵，而绝大多数回合用不到那些细节。

## 什么时候该拆出去

| 内容 | 放哪 |
| --- | --- |
| 触发条件、硬规则、读取顺序 | `SKILL.md` |
| 长表格、领域知识、边界情况枚举 | `references/` |
| 需要确定性结果的步骤（解析、校验、转换） | `scripts/`，并配 `tests/` |
| 需要人拍板的取舍 | 不问文件，问用户 |

## 引用约定

- 从 `SKILL.md` 引用本文件用相对路径：`references/example-check.md`。
- 不要在 `SKILL.md` 里用绝对路径或机器相关路径，`./scripts/validate.sh` 会检查引用是否存在。
